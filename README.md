# Eiffel — Portfolio premium rose

Portfolio responsive en HTML, CSS et JavaScript. Design éditorial premium, tons rose poudré et bordeaux, animations fluides, sans cartes.

## Tester
1. Décompresse le ZIP.
2. Ouvre le dossier dans VS Code.
3. Lance `index.html` dans ton navigateur ou utilise l'extension Live Server.
4. Les polices Google Fonts nécessitent une connexion Internet ; des polices de secours sont prévues.

## À personnaliser
- Remplace `tonadresse@email.com` dans `index.html`.
- Remplace les projets d'exemple par tes projets réels.
- Ajoute les liens vers tes dépôts GitHub quand ils sont disponibles.
- Ajuste les compétences selon ton niveau réel.

## Publication GitHub Pages
Crée un dépôt, envoie les fichiers, puis ouvre **Settings → Pages**. Sélectionne **Deploy from a branch**, `main` et `/ (root)`, puis enregistre.
